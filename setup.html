Local LLM 코딩 에이전트 설치

새 PC에서 처음부터 웹 UI가 돌아가기까지의 순서입니다. 위에서 운영체제와 GPU 메모리를 고르면 아래 명령이 거기에 맞게 바뀝니다. 끝낸 단계는 체크해 두세요 — 이 브라우저에 기억됩니다.

0 / 8
설치하는 것: Ollama(LLM 실행기) · 모델 2개 · Docker + SearXNG(웹 검색) · Python 패키지 · Node 패키지. 모델 다운로드가 가장 오래 걸립니다(). 전체 30분 ~ 1시간.

왜 커스텀 모델을 만드나: Ollama 기본 컨텍스트는 4K 라 에이전트가 여러 단계를 거치면 앞 내용을 잊습니다. num_ctx 32768 로 늘린 모델을 …-cline 이름으로 만들어 씁니다. 웹 UI는 기본적으로 이 커스텀 모델만 고를 수 있게 되어 있습니다.

비전 모델 qwen2.5vl:7b: 이미지 읽기용(사진 설명, 글자·표 옮겨 적기). 이미지를 안 쓸 거면 건너뛰어도 됩니다.

성능 설정 (권장)

긴 컨텍스트의 메모리 사용이 절반 정도로 줄어듭니다. 설정 후 Ollama 를 껐다 켜세요(트레이 아이콘 → Quit → 다시 실행).

4

웹 검색 엔진 SearXNG 켜기

SearXNG 는 검색어를 구글·빙·덕덕고 등에 대신 보내 결과를 모아 주는 무료 검색엔진입니다. 에이전트의 웹 검색·이미지 검색이 이걸 씁니다. Docker Desktop 을 먼저 켜 두세요.

설정 파일의 json 줄이 핵심입니다. 없으면 에이전트가 검색 결과를 읽지 못합니다. --restart unless-stopped 로 Docker 가 켜질 때 같이 켜집니다.

확인

날씨 기능은 SearXNG 없이 인터넷만 있으면 됩니다. 웹 검색이 필요 없으면 이 단계를 건너뛰어도 나머지는 동작합니다.

다음부터 켤 때 (재부팅 후)

Ollama 는 자동으로 켜집니다. Docker Desktop 만 켜 두면 SearXNG 도 같이 켜집니다. 남은 건 두 터미널입니다.

문제가 생기면

화면 오른쪽 위 모델 칸이 비어 있고 전송이 안 됨

웹 UI는 허용된 모델(기본 )만 보여 줍니다. ollama list 에 그 이름이 있는지 확인하세요. 없으면 3단계의 ollama create 를 다시 실행합니다. 다른 이름을 쓰려면 백엔드를 켤 때 WEB_MODELS 를 지정합니다.

“모델 목록을 못 불러옴: 502 … Ollama 연결 실패”

Ollama 가 꺼져 있습니다. Ollama 앱을 실행하거나 터미널에서 ollama serve. 다른 PC 의 Ollama 를 쓰려면 백엔드를 켤 때 OLLAMA_HOST=http://그PC주소:11434.

웹 검색 답이 “search error …” 이거나 결과가 없음

docker ps 에 searxng 가 있는지, 4단계 확인 명령에서 숫자가 나오는지 봅니다. 403 이 나오면 settings.yml 에 json 이 빠진 것입니다 — 고친 뒤 docker restart searxng.

“address already in use” / 8010 포트가 이미 쓰임

다른 프로그램이 그 포트를 쓰고 있습니다. 백엔드를 --port 8020 처럼 다른 번호로 켜고, web/frontend/vite.config.js 의 http://localhost:8010 도 같은 번호로 바꿉니다.

이미지를 올렸는데 “see_image error”

비전 모델이 없습니다. ollama pull qwen2.5vl:7b. 다른 비전 모델을 쓰려면 백엔드를 켤 때 VISION_MODEL=모델이름.

답이 너무 느림 (단계마다 수십 초)

nvidia-smi 로 GPU 메모리를 봅니다. 게임·다른 AI 프로그램이 VRAM 을 쓰고 있으면 모델이 RAM 으로 밀려 느려집니다. 3단계 성능 설정도 확인하세요. 8–12 GB 라면 7B 구성을 고르세요.

명령줄로 python agent/codeact_agent.py 를 직접 돌리면 연결이 안 됨

명령줄 실행의 기본 Ollama 주소는 개발자의 다른 PC 로 되어 있습니다. 주소와 모델을 지정하세요.

그래프를 그려 달라고 했는데 그림이 안 나옴

pip install -r requirements.txt (web/backend 폴더) 후 백엔드를 다시 켭니다. 한글·Word·엑셀 파일을 못 읽을 때도 같습니다.

보안: 에이전트는 이 PC 에서 실제로 파이썬 코드를 실행합니다(삭제·시스템 명령은 차단). 웹 UI 는 내 PC(localhost)에서만 열리게 되어 있으니 다른 사람에게 주소를 열어 주지 마세요.
